Every year, small and medium-scale export businesses face heavy losses from rejected export batches — the underlying cause is almost always failed compliance.(1) This creates a need for a tamper-proof, economical system that maintains a universally trustable record for farm-to-fork traceability.(2) NOIR closes this gap: an IoT node that records data, stores it locally, and anchors it to a public blockchain whenever network connectivity is available.(3)
Stack and Hardware
The NOIR node is a rugged IoT device equipped with temperature and humidity sensors — the two factors most international compliance standards prioritize. It also includes a rechargeable LiFePO4 battery, thermal energy harvesting as a secondary power source, a SIM module for data transmission, an ESP32 microcontroller, a vibration sensor, and an LED status indicator — all enclosed in a thermally insulated, rugged housing(4) built to survive harsh agricultural conditions and extended transit.(5)
Readings are transmitted via MQTT to the backend, into a Merkle root, and anchored on a public Layer-2 blockchain.(6) The dashboard is NOIR's abstraction layer — authorized stakeholders view clean, readable data and download compliance certificates directly. Clicking "Download Compliance Certificate" automatically triggers on-chain verification of the underlying record.(7)
Workflow
To protect privacy, permanence, and trust, tamper-evidence is built into NOIR's core data pipeline, from capture to anchoring. (8)BLE sensors — ideal for plug-and-play deployment (9)— collect data on an event/delta basis, logging only meaningful changes rather than redundant repeats, which optimizes power. A sleep-wake cycle samples data at short, regular intervals and reacts instantly to sudden triggers,(10) so SMEs know immediately when conditions deviate from expected thresholds.(11)
LiFePO4 batteries offer strong cycle life, while solar or thermal (TEG) harvesting — chosen based on deployment type — significantly extends operating time between charges(12). Data stored locally is hashed, so any attempt to modify it becomes evident immediately. (13)When connectivity is available, buffered data is synced to the cloud in batches and written on-chain as a single Merkle root.(14)
This makes a public Layer-2 blockchain the right choice: anchoring costs a fraction of a rupee per batch, and farmers are never required to run or maintain any blockchain infrastructure themselves.(15) Anchors are publicly verifiable by anyone, giving the ledger genuine decentralization while an L2 keeps security and scalability practical — directly balancing the blockchain trilemma rather than sacrificing one side of it.(16) The dashboard provides a secure, permissioned view where authorized personnel access clean data and download verified compliance certificates within milliseconds.(17)
